TERRA INCOGNITA — СЕТЕВОЙ СЕРВЕР (ПЕРВЫЙ ЭТАП)

Что уже работает в этой сборке:
- подключение игры к сетевому узлу;
- создание комнат с названием, паролем, лимитом игроков и зерном;
- общий список активных комнат;
- вход по коду и проверка пароля;
- передача координат и отображение других игроков;
- закрытие комнаты при отключении её владельца.

ВАЖНО: это ранний сетевой прототип. Пока НЕ синхронизируются блоки и постройки,
инвентарь, существа, транспорт, бой, действия игроков и сохранение общего мира.
Серверная комната существует, пока подключён её создатель. Это ещё не полноценный
постоянный выделенный мир.

ЗАПУСК СЕРВЕРА
1. Нужен компьютер или облачный хостинг с Node.js 18 или новее.
2. Загрузите папку проекта на сервер.
3. В терминале в папке проекта выполните:
   npm install
   npm start
4. Сервер слушает порт 3000 (или порт из переменной PORT).
5. Проверка: откройте http://АДРЕС-СЕРВЕРА:3000/health — ответ должен быть {"ok":true}.

ПОДКЛЮЧЕНИЕ ИГРЫ
1. Откройте terra_incognita_network.html.
2. В меню «Мультиплеер / Серверы» введите адрес сервера, например:
   http://192.168.1.25:3000  (для устройств в одной Wi-Fi сети)
   https://ваш-домен.example (если хостинг выдал HTTPS-домен)
3. Нажмите «Подключиться к сети».
4. Создайте комнату или войдите в существующую.

ПРИМЕЧАНИЯ
- Для игры через интернет нужен публичный адрес и хостинг, который поддерживает
  постоянные Node.js-процессы и WebSocket/Socket.IO.
- localhost означает само устройство. На телефоне это не адрес компьютера/облака.
- Не публикуйте пароль от приватных комнат.
- Для реального релиза нужно добавить авторизацию, защиту от читов, лимиты запросов,
  синхронизацию мира и серверное сохранение.
